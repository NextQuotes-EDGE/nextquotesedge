## Overview

The BCS Charity Trust (Mercy Fellowship) platform is the official web presence for a charitable organization. It pairs a polished public site with a complete admin portal that lets staff manage donations, beneficiaries, volunteers, campaigns, CMS content, disbursements, and reports.

## Architecture

Built with **Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS**, with Framer Motion for polished transitions. The core is a TypeScript/Next front end with a live **Paystack** payment flow for donations, and a mock-data-backed service layer for the admin modules so the full workflow is demonstrable end-to-end.

## Key Features

- **Live Donations** — real Paystack checkout for accepting contributions.
- **Campaigns** — launch and track fundraising initiatives.
- **Beneficiaries & Volunteers** — manage those the organization serves and supports.
- **Disbursements** — record and report charitable payouts.
- **CMS & Reporting** — edit public content and generate organizational reports.
- **Roles & Teams** — role-based permissions across the admin portal.

This is a real-world nonprofit platform, structured to be deployable on Vercel and ready for production use by the trust.
