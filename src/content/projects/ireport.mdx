## Overview

IReport is a public-safety incident-reporting mobile application. Citizens can report incidents, flag missing or wanted persons, trigger SOS alerts, and maintain emergency contacts — while moderators review and validate submissions before they go public.

## Scope

This project is delivered as a **product design and mobile architecture** effort, combining a Turbo monorepo scaffold (`apps/mobile` with Expo Router) with exhaustive design and API documentation:

- **Detailed API surface** (`API_SURFACE.md`) defining the incident, person, SOS, and moderation endpoints.
- **Database schema** (`DATABASE_SCHEMA.md`) for incidents, users, moderators, and emergency data.
- **UI plan** with ~25 fully-specified screens and HTML mockups.

## Key Features

- **Incident Reporting** — structured submissions with location, category, and evidence.
- **Missing / Wanted Persons** — searchable registry with photos and status.
- **SOS & Emergency Contacts** — one-tap urgency with configured contacts.
- **Moderation** — review workflow keeps public data trustworthy.
- **Maps** — geospatial browsing of nearby incidents.

IReport demonstrates end-to-end thinking: from domain modeling and API design through to a functional mobile scaffold ready for implementation.
