## Overview

BPAMS is a high-performance church management system for UABCSP. It centralizes priest administration, postings, finance tracking, real-time messaging, and an e-library into one platform with a sleek glassmorphism interface.

## Architecture

Built with **Next.js 15 + React 19** and backed by **Supabase** for authentication, data, and real-time messaging. The UI uses **Tailwind CSS 4** alongside **MUI 7** to deliver a premium, glassmorphism design language.

## Key Features

- **Priest Administration** — profiles, assignments, and role management.
- **Postings** — track placements and rotations.
- **Finance Tracking** — monitor organizational finances with dashboards.
- **Real-Time Messaging** — instant communication powered by Supabase real-time channels.
- **E-Library** — digital resource management for the community.

BPAMS demonstrates a full-stack management platform combining a modern front-end design system with a fully managed BaaS backend, enabling fast delivery without sacrificing polish.
